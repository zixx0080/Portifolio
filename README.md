Também uso Google Fonts para as fontes da página. Bootstrap e as fontes são carregados pela internet, então alguns detalhes visuais podem não aparecer sem conexão.

## Como abrir

Não precisa instalar nada. Baixe ou clone o repositório e abra o `index.html` no navegador.

Se preferir, dá para iniciar um servidor local na pasta do projeto:

```bash
python -m http.server 8000
```

Depois, abra [http://localhost:8000](http://localhost:8000).
