# Ideias para o portfólio informal

Cada ideia abaixo representa uma seção própria do portfólio.

## Árvore de habilidades

Uma representação visual das minhas soft skills, organizada como uma árvore de habilidades. Cada habilidade pode aparecer como um ramo ou elemento que revele uma qualidade e, se fizer sentido, um exemplo de como ela aparece no meu jeito de trabalhar.

## Arsenal técnico

Uma seção para apresentar minhas hard skills como um arsenal técnico: linguagens, frameworks, ferramentas e tecnologias que conheço ou estou aprendendo. A apresentação pode deixar claro o que já usei em projetos e o que ainda estou estudando.

## Depoimentos

Um espaço com depoimentos de colegas de trabalho, professores e pessoas que participaram de projetos comigo. Os relatos podem destacar experiências de colaboração e pontos fortes que perceberam no meu trabalho.

## Compatibilidade com a vaga

No final do portfólio, incluir um quiz sobre minha personalidade e meu jeito de trabalhar. Com base nas respostas, o quiz apresenta o quanto meu perfil parece compatível com a empresa e com a vaga da pessoa visitante.

## Prompts para visualizar as ideias

Copie cada prompt separadamente para uma ferramenta de geração de imagens. Os prompts pedem mockups de interface para ajudar a visualizar como cada seção poderia ficar.

### Árvore de habilidades

> Crie um mockup visual de uma seção de site para um portfólio pessoal informal de um estudante de Desenvolvimento de Software Multiplataforma. A seção se chama “Árvore de habilidades” e apresenta soft skills como se fossem uma árvore de habilidades de um jogo: raízes, tronco e ramos conectados, com nós visuais para qualidades como criatividade, trabalho em equipe, adaptabilidade, curiosidade, disciplina e proatividade. Inclua pequenos espaços de exemplo junto a algumas habilidades, sem inventar histórias pessoais específicas. O visual deve ser acolhedor, criativo e organizado, com referências sutis a jogos e ilustração, mas ainda legível e adequado a um portfólio profissional. Mostre a interface de uma página web em desktop, com fundo claro, cores quentes, boa hierarquia visual e textos em português. Gere apenas a imagem do conceito da interface, sem código.

### Arsenal técnico

> Crie um mockup visual de uma seção de site chamada “Arsenal técnico” para o portfólio informal de um estudante de Desenvolvimento de Software Multiplataforma. Apresente hard skills em cartões organizados por categorias, como linguagens, frameworks, bancos de dados, ferramentas e colaboração. Use como exemplos Python, Java, C#, JavaScript, HTML, CSS, Flask, Spring, Bootstrap, MariaDB, SQLite, Git, Docker, Figma e GitHub. Diferencie com clareza tecnologias já usadas em projetos das que ainda estão em aprendizado, sem inventar níveis de domínio. Use uma metáfora visual leve de inventário ou equipamentos de aventura, sem deixar a página infantil. Interface web desktop, visual moderno e simpático, fundo claro, cores quentes, cartões bem alinhados, textos em português e leitura fácil. Gere apenas a imagem do conceito da interface, sem código.

### Depoimentos

> Crie um mockup visual de uma seção web de portfólio chamada “Depoimentos”, para um estudante de Desenvolvimento de Software Multiplataforma. Mostre cartões elegantes e acolhedores para relatos de colegas de trabalho, professores e pessoas que participaram de projetos com ele. Cada cartão deve ter espaço para uma citação, nome, função e contexto da colaboração, mas use apenas textos claramente marcados como “Depoimento a adicionar” ou conteúdo fictício identificado como placeholder — não invente recomendações reais. O design deve transmitir confiança, colaboração e proximidade, com fundo claro, cores quentes, tipografia legível e pequenos detalhes gráficos discretos. Mostre uma página web desktop bem organizada, em português, adequada a um portfólio informal e profissional. Gere apenas a imagem do conceito da interface, sem código.

### Compatibilidade com a vaga

> Crie um mockup visual da seção final de um portfólio informal chamada “Combina com essa vaga?”. A interface mostra um quiz curto e amigável sobre estilo de trabalho e personalidade, com opções de resposta em botões ou cartões, indicador de progresso e uma pergunta por vez. Inclua uma tela de resultado com uma porcentagem ilustrativa de compatibilidade e uma explicação breve de quais preferências parecem combinar com a vaga. Deixe explícito no próprio design que o resultado é uma estimativa baseada nas respostas, não uma avaliação objetiva ou garantia de contratação. Use linguagem inclusiva em português, visual acolhedor e profissional, fundo claro, cores quentes e referências sutis a jogos ou missões. Mostre a interface de um site desktop, com o quiz e o resultado apresentados de forma visualmente clara. Gere apenas a imagem do conceito da interface, sem código.
